# Мониторинг заказов интернет-магазина

**Учебный проект на синтетических данных (август - октябрь 2026).**  
[Дашборд] (https://datalens.ru/r2da6djqhbwwa-dashbord-shop-orders?_share_link=org)

## Задача
Представить показатели заказов так, чтобы менеджер мог быстро оценить динамику стоимости доставленных заказов, распределение по городам и категориям, а также статусную структуру заказов.

## Что сделано
- Исходная выгрузка: **512 строк**, включая 12 повторных записей. После удаления дублей по `order_id`: **500 уникальных заказов**.
- Подготовка данных в Python/pandas: нормализация даты, проверка пропусков, создание технических полей `order_count`, `is_delivered`, `is_finished`, `delivered_amount`.
- Проверки через SQL/SQLite: группировки по месяцам, городам, категориям, расчёт доли доставленных среди завершённых заказов.
- Визуализация: интерактивный дашборд в Yandex DataLens с KPI и срезами по месяцам и категориям.

## Результаты на учебных данных
- Доставлено **367** заказов из **500**; отменено **74**; ещё в обработке **59**.
- Стоимость доставленных заказов: **2,096,862 ₽** (это модельная стоимость товаров, не прибыль и не комиссия маркетплейса).
- Среди завершённых заказов доставлено **83.2%**.
- Наибольшая стоимость доставленных заказов по городам у города **Москва**, по категориям у **Дом и ремонт**.

## Что важно при интерпретации
- Продолжительность доставки известна только для `delivered`.
- Заказы `in_progress` не включены в знаменатель доли доставленных среди завершённых.
- Данные синтетические, поэтому результаты демонстрируют логику работы с метриками, а не реальные рыночные тенденции.

## Файлы
- `data/orders_raw.csv` - исходные 512 строк, включая дубли.
- `data/orders_bi_ready.csv` - итоговая таблица для BI (на случай трудностей с ноутбуком).
- `notebook/01_orders_bi.ipynb` - код Python, подготовка данных и SQL-запросы; запускается в Google Colab.
- `sql/analysis.sql` - дополнительные SQL-запросы с комментариями.
- `screenshots/dashboard.png` - добавь скриншот дашборда после его создания.

## Как повторить
1. Открой Google Colab и импортируй `.ipynb` через «Файл» → «Загрузить блокнот».
2. Запускай ячейки сверху вниз; в первой загрузи `data/orders_raw.csv`.
3. Скачай получившийся `orders_bi.csv` и загрузи его в Yandex DataLens через подключение «Файлы».
4. Построй KPI, диаграммы и селектор, опубликуй публичную ссылку, затем вставь её в начало этого файла.
